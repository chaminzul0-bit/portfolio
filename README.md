## Бүтээлч санаа

Сайт бол **ширээн дээр эгнүүлсэн 5 ягаан хавтас**. Хавтас бүр нэг хуудас:

| № | Хавтас | Агуулга |
| --- | --- | --- |
| 01 | нүүр | Нэр, чиглэл, нэг өгүүлбэр, агуулгын жагсаалт |
| 02 | миний тухай | Зураг, намтар, товч баримтууд |
| 03 | ур чадвар | Сэтгүүлийн индекс шиг дугаартай технологийн жагсаалт |
| 04 | бүтээлүүд | 3 бүтээл — зураг, тайлбар, сайт ба GitHub холбоос |
| 05 | холбоо барих | Имэйл (хуулах товчтой), GitHub, LinkedIn |

- Хаалттай хавтас бүрийн ард тухайн хуудасны **жижиг зурвас** (peek) цухуйж харагдана.
- Хавтасны **цагаан шошго** эсвэл зурвас дээр дарахад тэр хавтас **дэлгэгдэж** нээгдэн, бусад нь нарийсна.
- Нээгдсэн хавтасны нуруун дээр том **налуу гарчиг** гарч ирнэ, агуулга мөр мөрөөрөө гарч ирнэ.
- `←` `→` товчоор хавтас солино. URL `#about`, `#projects` болж өөрчлөгдөх тул шууд холбоос, хөтчийн "буцах" товч ажиллана.
- Гар утсан дээр хавтаснууд дээрээс доош давхарлаж, дарахад доош задарна.
- 🥚 **Easter egg:** нүүр хуудасны дугуй тамган дээр 3 удаа дарахад "АЖИЛД АВЪЯ!" тамга дарагдана.

**Санааны эх сурвалж:** Pinterest дээрх ягаан хавтас бүхий social media дизайны постероос хавтас, шошгоны санааг авсан. Код, зохион байгуулалт, харилцан үйлдлийг өөрөө бичсэн.

## Технологи

- **HTML, CSS, JavaScript** — framework, бэлэн загвар ашиглаагүй
- **CSS Flexbox** — хавтас нээгдэх анимэйшн (`flex-grow: 0 → 1`)
- **CSS `writing-mode`** — босоо шошго, гарчиг
- **`radial-gradient`** — хавчуургын хотгор булан
- **History API** (`pushState`, `popstate`) — URL hash ба буцах товч
- **Clipboard API** — имэйл хуулах
- Фонт: [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond), [Manrope](https://fonts.google.com/specimen/Manrope) (Google Fonts)
- Байршуулалт: Vercel

## Файлын бүтэц

```
index.html   – 5 хавтасны бүтэц
style.css    – хавтасны загвар, анимэйшн, responsive
script.js    – мэдээлэл оруулах, хавтас нээх, харилцан үйлдэл
data.js      – бүх хувийн мэдээлэл (нэр, ур чадвар, бүтээл, холбоос)
assets/      – зураг, favicon
```

Агуулгыг солихдоо зөвхөн `data.js`-ийг засна.

## Хэрхэн ажилладаг вэ (товч)

1. `.cabinet` нь `display: flex`. Хавтас бүр (`.folder`) хаалттай үед `flex-grow: 0` тул нарийхан.
2. `openFolder(id)` функц сонгосон хавтсанд `.open` класс нэмж, бусдаас хасна.
3. `.open` үед `flex-grow: 1` болж үлдсэн зайг эзэлнэ; CSS `transition` үүнийг жигд хөдөлгөөн болгоно.
4. `.peek` бүдгэрч, `.content` гарч ирнэ; `.stagger` элементүүд ээлжилсэн `transition-delay`-тэй.
